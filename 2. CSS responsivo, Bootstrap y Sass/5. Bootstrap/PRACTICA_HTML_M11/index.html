Claude Code

Claude Code es un asistente de codificación basado en IA de Anthropic, diseñado como una herramienta de línea de comandos (CLI) que actúa directamente en tu terminal.

Claude AI

Claude AI es un avanzado chatbot de inteligencia artificial generativa y una familia de modelos de lenguaje (LLM) desarrollados por Anthropic, una startup de seguridad de IA fundada por ex-investigadores de OpenAI.

Claude Sonnet 4.5

Claude Sonnet 4.5 es el modelo de IA más avanzado y capaz de Anthropic, optimizado para el uso autónomo de herramientas, programación de alto nivel y la construcción de agentes complejos.

IA Constitucional (Anthropic)
Es el método de entrenamiento que hace que la inteligencia artificial Claude sea única. En lugar de solo aprender de humanos, el modelo sigue una "constitución" de principios éticos escrita para evaluar sus propias respuestas; esto garantiza que sea más segura, honesta y menos propensa a generar contenido dañino por cuenta propia.

Medio Interno (Claude Bernard)
Es el concepto pilar de la biología que explica que los seres vivos poseen un ambiente fluido interno (sangre y linfa) que se mantiene estable. Gracias a este equilibrio constante, nuestras células pueden funcionar correctamente sin importar si afuera hace frío, calor o si las condiciones del entorno cambian drásticamente.

Es el sistema de valores que guía a la IA Claude. A diferencia de otros modelos, utiliza una "constitución" interna para supervisar su propio comportamiento, asegurando que sus respuestas sean seguras, honestas y alineadas con principios humanos de forma autónoma.

Concepto científico que define el ambiente fluido donde viven nuestras células. Es la capacidad de los organismos para mantener una estabilidad interna constante (como la temperatura o el pH), permitiendo que la vida continúe aunque las condiciones externas sean extremas o cambien.

Es la capacidad técnica de Claude para procesar y recordar una cantidad masiva de información en una sola interacción. Esto le permite analizar documentos extensos, libros completos o bases de datos enteras de una sola vez, manteniendo la coherencia y el detalle sin olvidar lo mencionado al principio de la conversación.
