REPASO DE HTML

HTML, acrónimo en inglés de HyperText Markup Language, hace referencia al lenguaje de marcado utilizado en la creación de páginas web. Este estándar que sirve de referencia del software que interactúa con la elaboración de páginas web en sus diferentes versiones.

Etiquetas HTML

A continuación voy a indicarte cuáles son las etiquetas HTML más usadas en una lista ordenada y también te indicaré su finalidad. Voy a centrarme en las principales etiquetas y sobre todo las que están soportadas en HTML 5. Ahí van:

  1. DOCTYPE html: Indica al navegador que el documento está basado en el estándar HTML5
  2. html: Representa la raíz de un documento HTML. Todos los demás elementos de la estructura HTML deben ser recogidos dentro de estas etiquetas.
  3. head: Contiene metadatos/información para el documento HTML, como su título y enlaces a hojas de estilo.
  4. h1,h2,h3,h4,h5,h6: Representa encabezados de diferentes niveles en el documento HTML.

Tambien es importante mencionar que asi como existen listas ordenadas tambien existen listas no ordenadas, para que lo puedas notar voy a mostrar la misma informacion en una lista no ordenada:

Estructura HTML

En HTML es importante tener una organizacion estructurada para mostrar los elemnetos de manera ordenada no solo de manera visual para el usuario sino que para nosotros como programadores podamos entender el codigo y que otros sean capaces de entenderlo

Con HTML se pueden hacer cosas increibles como sitios web, tablas, formularios, etc.
