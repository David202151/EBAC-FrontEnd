ELEMENTOS DE BLOQUE

<H1> es un elemneto de bloque

Ya que al agregar otro elemento de bloque como lo es p este texto se acomoda con un salto de linea

<ARTICLE>

Es un elemento de bloque que nos ayuda a organizar nuestro codigo para asefurarnos de que es una estructura HTM semantica.

ELEMENTOS DE LINEA

Son elemetos de HTML que se acomodan a lo ancho de la pantalla, estos a diferencia de los elementos de bloque no generan un salto de linea.

Ejemplos:

<SPAM>

Un ejemplo de estos elementos es la etiqueta spam ya que los elementos en estas etiquetas se comodan a lo ancho de la pantalla y no generan un salto de linea

ETIQUETA <A>

La etiqueta a tambien es un elemento de linea ya que se acomodan a lo ancho de la pantalla
